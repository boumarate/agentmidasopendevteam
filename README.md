## Security Pipeline

Every contribution passes through a 6-layer review:

1. **CLA Signature** -- Required before first PR
2. **Automated Scan** -- Dependency audit + static analysis
3. **Code Review** -- Agent FORGE AI code review
4. **Security Audit** -- Agent CAPTAIN OWASP checks
5. **UX Review** -- Agent RADAR accessibility + design
6. **Final Approval** -- MIDAS PRIME quality gates

**Zero Dependency Rule:** No new npm packages without prior approval.

## UX Design Principles

1. **10-Year-Old Test** -- If it needs a manual, redesign it
2. **Mobile-First** -- Design for 375px first
3. **Instant Feedback** -- Every action gets visual feedback
4. **Consistent Design** -- Dark theme (#0A0A0A), gold (#D4AF37), Inter font
5. **Progressive Disclosure** -- Essential info first
6. **Accessibility** -- WCAG 2.1 AA compliance
