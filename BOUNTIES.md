# Agent Midas Bounty Board

41 bounty items across 10 categories. Claim a bounty, build it, get paid.

## How Bounties Work

1. Pick a bounty from the list below
2. Open an issue to claim it (prevents duplicate work)
3. Fork the repo and create a `bounty/XX-app-name` branch
4. Build the app following [CONTRIBUTING.md](./CONTRIBUTING.md) standards
5. Submit a PR referencing the bounty number
6. Pass the 6-layer security review
7. Get paid via Stripe

## Claiming a Bounty

1. Check the issues tab to see if a bounty is already claimed
2. Open a new issue: "Claiming Bounty #XX - App Name"
3. You have 14 days to submit a PR (extensions available on request)
4. If no PR is submitted, the bounty returns to the pool
